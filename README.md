# LED Ping Pong Game (VHDL)

這是一個雙人對戰的乒乓球遊戲，使用 8 顆 LED (`o_led`) 作為球，並透過兩個開關 (`i_swL`, `i_swR`) 進行擊球。

## 功能簡介

1.  **發球與移動**：
    *   重置後，球從左側發向右側 (MovingR)。
    *   球在 LED 上移動，速度是隨機變化的（透過 LFSR 產生隨機數）。

2.  **擊球判定**：
    *   **成功擊球**：當球到達最旁邊的 LED (左邊第 7 顆或右邊第 0 顆) 且玩家按下對應開關時，球會反彈並加速/變速。
    *   **失誤 (太晚按)**：球已經到底，但玩家沒按開關，對手得分。
    *   **犯規 (太早按)**：球還沒到底，玩家就按開關，視為揮棒落空，對手得分。

3.  **計分系統**：
    *   **Lwin (左方獲勝)**：左邊 4 顆 LED 顯示左方分數，右邊全滅。需按下左方開關重新發球。
    *   **Rwin (右方獲勝)**：右邊 4 顆 LED 顯示右方分數，左邊全滅。需按下右方開關重新發球。
    *   分數最高累積到 15 分。

4.  **隨機速度**：
    *   內建一個 16-bit LFSR (Linear Feedback Shift Register) 亂數產生器。
    *   每次成功擊球反彈時，球的移動速度會隨機改變，增加遊戲難度。


## 狀態機 (FSM)

系統主要由四個狀態組成：
*   **MovingR**: 球向右移動中。
*   **MovingL**: 球向左移動中。
*   **Lwin**: 左方得分狀態 (顯示分數，等待發球)。
*   **Rwin**: 右方得分狀態 (顯示分數，等待發球)。
